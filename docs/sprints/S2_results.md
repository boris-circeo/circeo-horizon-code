### Findings (factual, n = 5 synthetic seasons; indicative only)

1. E1 (ensemble value, same 15 d horizon): ENS_g0 beats B1_15d by +26 MWh (+1.7 %) on average, 3/5 wins, paired t = 1.0 (not significant). The gain is concentrated on seeds 104/105 (+65, +104) where B1_15d was worst; seeds 102/103 are slightly negative. Seasonal spread varies very little between seeds (3.09-3.25 m/s), so no stratification effect is visible (corr +0.05).
2. The ensemble does not beat the 5 d deterministic MPC (ENS_g0 - B1_5d = -41 MWh, 1/5 wins): it recovers about 40 % of the 15 d vs 5 d loss only (regret 14.8 % vs 12.6 % / 16.2 %).
3. Risk effect: CVaR gamma 0.3 vs 0 changes the mean by -11 MWh (2/5 wins); worst seed 1362 vs 1378 MWh, P10 1417 vs 1428 MWh: no measurable tail benefit, no mean cost beyond noise.
4. Refiner: B1_5d_REF - B1_5d = +46 MWh (4/5 wins; seed 102 +157), ENS_g03_REF - ENS_g03 = +44 MWh (5/5, t = 5.8, the only clearly significant effect), hold fraction drops to 2-7 %.
5. Best causal policy: B1_5d_REF, regret 10.0 +- 1.8 % vs oracle (S1 best 12.6 %); ENS_g03_REF 13.0 %. B1_5d_REF beats ENS_g03_REF on 5/5 seeds (-54 MWh, t = -2.7): the 5 d horizon with refinement dominates the 15 d ensemble with zero terminal value in this synthetic setting.
